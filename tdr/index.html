Setup & Help

Windows PC (all features)

Open this checklist in Google Chrome or Microsoft Edge. To make it an app icon, click Install Chrome App at the bottom of this screen. If Chrome blocks the one-click install, open the browser menu, choose Cast, save, and share, then Install page as app. The Empire icon lands on your desktop and taskbar and always opens in that browser.

System check

Click Run System Check before using this on a new tablet or computer. It checks Chrome support, folder saving, OneDrive setup, local backup, and the office send button.

Tablet setup (Android)

Best setup: on the Android tablet open Google Chrome and go to the Empire TDR web address (the one ending in github.io that was set up for you). Tap the Chrome menu (⋮), then tap Install app (or Add to Home screen). The Empire icon lands on the tablet home screen and from then on it opens full-screen like a normal app — even with no internet.

Because it is installed from a web address, it auto-updates: when the office publishes a new version, the tablet picks it up the next time it is online.

iPad note: Chrome on iPad is still limited by Apple browser rules. The checklist will work for typing, photos, saving, and sharing, but direct folder saving is limited. The best one-click method on iPad is the SEND TO OFFICE button with a Microsoft Power Automate OneDrive flow.

Saving on a tablet: use SEND TO OFFICE for one-click filing into Microsoft OneDrive. If the flow is not set up yet, use Send to OneDrive and pick OneDrive from the tablet share sheet.

Photos: tap the green Take Photo button. The app compresses photos before saving so the tablet does not run out of storage as quickly.

Save records to a folder (PC)

Click Choose Folder once and pick your OneDrive folder. After that, Save to Folder writes each record into it, named by model, serial, and date. Saving the same unit again updates the same file.

If the buttons do nothing

You are likely viewing the file inside a OneDrive or email preview, which does not run the app. Open it in a real browser first: on a PC use Chrome or Edge; on an iPad tap Share, then Open in Safari.

One-tap SEND TO OFFICE → OneDrive (one-time setup)

This is the recommended way to file checklists from the tablet. You build one Power Automate flow that drops every finished checklist straight into the Logistics - Documents folder, then paste its address below. After that, the big green SEND TO OFFICE button files each checklist by itself — no share sheet, no picking a folder.

Build the flow once (about 5 minutes):

1. Go to make.powerautomate.com and sign in with the Empire Safe Microsoft account.
2. Create → Instant cloud flow. Name it “Empire TDR to OneDrive” and pick the trigger When an HTTP request is received.
3. Add a step: OneDrive for Business → Create file.
  • Folder Path: /Logistics - Documents (the same folder as OneDrive - Empire Safe Company Inc\Logistics - Documents).
  • File Name: use the fileName value from the request (or triggerBody()?['fileName']).
  • File Content: the body of the request (triggerBody()).
4. Save. Re-open the trigger step and copy the HTTP POST URL it generated.
5. Paste that URL in the box below and tap Save.

Tip: each file is named by model, serial, and date, so re-sending the same unit updates the same record. If the tablet is offline, the checklist is held on the device — tap Retry Unsent once it is back online.
